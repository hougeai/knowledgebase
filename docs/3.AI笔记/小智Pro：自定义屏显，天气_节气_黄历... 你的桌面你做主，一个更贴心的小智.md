## 1. 需求分析

1. 自定义屏显：通过Web前端勾选：天气、空气质量、农历/阳历、节气、黄历等；
2. 多设备适配：支持设置页面切换间隔（5s-60s），适配不同屏幕尺寸；
3. 地理感知：自动获取设备地理位置，无需手动配置城市；
4. 数据缓存：云端聚合数据并缓存，避免频繁调用第三方API；

## 2. 架构设计

云端负责屏显配置、数据存储。

设备端负责布局不同类型的信息。

## 3. 云端

### 3.1 用户前端

支持用户选择显示天气、空气质量、农历/阳历日期、节气、黄历等信息；

![](https://i-blog.csdnimg.cn/img_convert/3001152e9b37ce9698bb5d1b5cfd8830.png)

后端会自动获取设备地理信息。

如果地理位置识别错误，前端可手动修改：

![](https://i-blog.csdnimg.cn/img_convert/960dbae010da0f21b56a48b2a5bd6dcc.png)


### 3.2 云端服务层

根据设备位置，调用天气API获取当地天气，空气质量指数(AQI)；

根据当前日期，调用日历API获取日期、节气、黄历等信息。

目前接入如下字段：

🌤️ **天气信息**：实时显示当地天气状况，让你出门前了解天气情况。

🌆 **空气质量**：显示实时AQI指数，帮你决定是否需要佩戴口罩或调整户外活动计划。

📅 **日期时间**：支持显示阳历和农历日期，让你随时了解传统节日和重要纪念日。

🌿 **节气物候**：中国传统的二十四节气和物候信息，让你与自然节律保持同步，更好地安排养生计划。

🔮 **黄历宜忌**：每日黄历信息，包括宜/忌，为你的决策提供传统文化参考。

⭐ **二十八星宿**：每日星宿信息，满足你对传统文化和天文学的好奇。

📜 **历史上的今天**：历史上的今天发生的重大事件。


## 4. 设备端

设备上电后，会请求后端。

根据前端配置的字段，返回对应的内容，缓存到本地。

根据翻页间隔，动态翻页显示不同文本。

目前`小智Pro`固件支持主流的两种屏幕类型：
- OLED（有机发光二极管屏）
- LCD（液晶显示屏）

为了适配不同的屏幕尺寸，单页显示条目数量：

- OLED 128x32：1条
- OLED 128x64：2条
- LCD Display：4条

超出屏幕宽度，将滚动显示~
