## 1. 系统架构

架构特点：模块化设计和微服务架构，支持弹性扩展和负载均衡。

![](https://i-blog.csdnimg.cn/img_convert/c2d1dd42792d65a89ccb4bac7adb2c25.png)

图中，

**终端设备层**：以`AtomS3R`举例，支持任意接入`小智AI客户端`的开发板。

服务端，目前最新支持到`客户端`的`1.8.5`版本，持续跟进中。

**云端服务层**：集成语音识别、LLM、语音合成等独立管线，支持高并发、低延迟的智能对话。架构如下：

![](https://i-blog.csdnimg.cn/img_convert/cef87dc84cb102ab1846d0dfde5a6d11.png)

**管理服务层**：管理后台与用户前端，采用Vue3搭建，支持多终端、多角色的灵活管理和可视化。

![](https://i-blog.csdnimg.cn/img_convert/81133c5258ab67f5bf7bda76fe560148.png)

**数据存储层**：
- MySQL 数据库：密钥和配置持久化；用户认证；资源管理；日志存储；
- Redis 缓存：密钥状态缓存；常用资源缓存；音色缓存；
- EMQX 消息队列：MQTT 协议交互；

**基础设施层**：支持单机部署和集群部署

![](https://i-blog.csdnimg.cn/img_convert/c84b19abf6556820662a2e4c81565e2d.png)

整个服务端，拆解成 6 大功能模块，独立打包，docker 镜像大小如下：

![](https://i-blog.csdnimg.cn/img_convert/876e1abc844912d8f69bcd5e6ba4e7cf.png)

单机部署 `docker-compose` 一键拉起；

集群部署基于 `K8s`，包含 6 个 Deployment，每个最低1个副本：

![](https://i-blog.csdnimg.cn/img_convert/e6cab29fed31a1ce53f3cbcc243d37cf.png)

## 2. 支持功能

**用户前端**:
- 设备管理：验证码添加设备；配置角色；声纹识别；对话记忆；
- 角色管理：自定义角色提示词；
- 大模型管理：接入自定义的 LLM，支持 OpenAI/Coze API 格式；
- 音色管理：支持 3s 音色克隆；

![](https://i-blog.csdnimg.cn/img_convert/968a44a93ca06c2f14561538d03f46d5.jpeg)


**管理后台**:

- 系统管理：

![](https://i-blog.csdnimg.cn/img_convert/1aba9b684704436b23b89fdadadb2266.png)

- 资源管理：

![](https://i-blog.csdnimg.cn/img_convert/23044af4f3903d0087ff8b20333dc568.png)




**AI服务**：

- 主服务端：支持 WebSocket / MQTT+UDP 通信协议；
- LLM 端：支持 OpenAI / Coze 两种协议，流式/非流式输出，接入 MCP；
- ASR 端：支持 VAD + ASR + 声纹识别，双向流式；
- TTS 端：支持 Dashscope / Volcengine / 本地部署，双向流式；

## 3. 部署方案

为了满足`高可用、可扩展`的设计原则，完整方案部署在 k8s 集群上。

进一步，为了满足`低成本、少运维`的原则，这里选择了 `sealos`。

> 关于 sealos & 注册体验：[https://bja.sealos.run/?uid=QDGJoX2_Qp](https://bja.sealos.run/?uid=QDGJoX2_Qp)

### 3.2 应用

然后，新建应用：

![](https://i-blog.csdnimg.cn/img_convert/d5b90239c4e314daf9fa7575e0d6614a.png)

以新建 `espbot-frontend`为例：

![](https://i-blog.csdnimg.cn/img_convert/4cc709c701884c4da6856aa84cfbfaed.png)

你只需要在前端页面点点点，sealos 帮你写好了一堆 yaml 文件，底层调用 `kubectl apply -f` 拉起应用：

- 镜像源：选择镜像，可以是私有仓库；
- 部署模式：弹性伸缩，可根据 cpu/内存 使用率进行弹性扩展实例；
- 极低成本：配置选择0.1c/128M，而阿里云ACS上最小得0.25c/512M；

你看，每天仅需 **0.07** 元，即可部署一个`前端应用`的pod，包括：`用户前端和管理后台`，只需放开两个端口：

![](https://i-blog.csdnimg.cn/img_convert/2d8d614337815d3615cd1999bc8e5779.png)

公网访问，可以用 sealos 的二级域名，连域名费用都省了；如果用自己域名，只需添加一条 DNS。
