```mermaid
sequenceDiagram
    participant Client as 客户端
    participant MQTT_Server as MQTT Broker
    participant Server as 服务端
    participant UDP_Server as UDP 服务器

    Client->>MQTT_Server: 连接 (connected)
    MQTT_Server->>Server: 发布 connected 消息

    Server->>Server: 创建 handler 并生成 key/nonce
    Server->>Client: 发送 hello 响应

    Client->>MQTT_Server: 发送 hello 消息
    MQTT_Server->>Server: 转发 hello 消息

    Server->>Server: 处理 hello 消息并验证设备信息
    Server->>Server: 加载语音、角色、LLM 等配置
    Server->>Server: 启动 ASR、TTS、LLM 客户端
    Server->>Server: 设置 ASR/TTS 会话
    Server->>Client: 发送 hello 响应（包含 UDP 配置）

    Client->>UDP_Server: 发送加密的音频数据包
    UDP_Server->>Server: 解密并分发给对应的 handler

    Server->>Server: 处理 UDP 数据包并缓存音频
    Server->>Server: 如果 ASR 就绪则处理音频

    Client->>MQTT_Server: 发送 mcp 消息 (initialize 请求)
    MQTT_Server->>Server: 转发 mcp initialize 请求

    Server->>Client: 发送 mcp initialized 响应
    Server->>Client: 发送 tools/list 请求

    Client->>MQTT_Server: 回复 tools/list 结果
    MQTT_Server->>Server: 转发 tools/list 结果

    Server->>Server: 存储 IoT 工具列表
    Server->>Server: 触发 tools 事件

    Client->>MQTT_Server: 发送 mcp 工具调用请求
    MQTT_Server->>Server: 转发 mcp 工具调用请求

    Server->>Server: 处理工具调用并返回结果
    Server->>Client: 发送 mcp 工具调用结果

    Client->>MQTT_Server: 发送 listen/start 指令
    MQTT_Server->>Server: 转发 listen/start 指令

    Server->>Server: 启动 ASR 会话并开始监听音频
    Server->>Server: 接收音频包并进行识别

    Server->>Server: 使用 LLM 生成回复文本
    Server->>Server: 调用 TTS 生成音频
    Server->>UDP_Server: 发送 TTS 音频数据包
    UDP_Server->>Client: 接收音频并播放

    Client->>MQTT_Server: 发送 abort 指令
    MQTT_Server->>Server: 转发 abort 指令

    Server->>Server: 中断 LLM 和 TTS 会话
    Server->>Client: 发送 goodbye 消息

    Client->>MQTT_Server: 发送 goodbye 消息
    MQTT_Server->>Server: 转发 goodbye 消息

    Server->>Server: 清理资源并关闭连接

    loop 定时清理过期连接
        Server->>Server: 检查 ipPortMap 中的过期会话
        Server->>Server: 删除过期的 UDP 映射
    end
```
